The motion, in five steps

The boring stack, in order. Nothing expensive runs before something cheap has passed.

  1. 01

    Compile the ICP

    Split the profile into filters a provider can filter on, and checks that run per row. The buyer is a function, not a title.

    pipeline/icp.md
  2. 02

    Count, then qualify

    Free gates first. Rows that fail are recorded, not bought. Every drop carries a reason.

    pipeline/rules.json
  3. 03

    Find the person

    Search the buyer's function — marketing, growth. A "decision makers" list is a map of the company, not your committee.

    treg.people.search
  4. 04

    Find, then verify the email

    A routed waterfall tries providers cheapest-per-hit, misses free. Only a verified-deliverable address enters the sequence.

    treg.people.email.find
  5. 05

    Write back

    Company → person → list entry. Upserted on the domain and the email, so a re-run updates instead of duplicating.

    pipeline/lib/attio.mjs

Writeback is the product

Slack is the interface; the CRM stays the database. This pipeline never touches Slack — it writes the records a human reviews. Upserts, matched on the unique attribute, so the second run updates.

The ICP is the prompt
icp.md is the artifact. Edit the filters and the
        checks; the pipeline re-compiles. No hard-coded lists.

      
Rules, not vibes
Thresholds, spend caps and the owner of the stop live in
        rules.json. Every drop has a reason to point at.

      
Transfer, not a retainer
Repo, runbook and a named owner. Your team runs the motion
        without us — which is the point.

    

  


  
  

    
What we deliberately did not automate

    
Restraint is the differentiator. A workflow that shouldn't exist is a cost, not a feature.

    
    
      
  • No sending. This pipeline proposes; a person approves. Nothing leaves the building from here —
        drafts-only, with a confidence gate downstream.
    • 
      
  • No buying the whole list. 21 of 48 rows were dropped on a free check. Enriching all of them
        would have cost roughly $4.12; we spent $2.33.
    • 
      
  • No "decision makers" endpoint. One such call returned 45 senior people and no marketing —
        the buyer wasn't in the room. Search the function instead.
    • 
      
  • No second email provider by default. The routed waterfall already bills misses at $0.00 on
        per-success providers; a hand-rolled second call is just a second bill.
    •

Run it

    
The site is static. The pipeline is one file with no dependencies.

    

      

        
replay — no keys, no spend

        
git clone <repo> && cd origination-engine
node pipeline/run.mjs --replay
# → 27 passed · 20 deliverable · $0.1165/lead
npx serve site        # or: python3 -m http.server -d site

      

      

        
live — your keys

        
cp .env.example .env   # TREG_TOKEN, ATTIO_TOKEN
node pipeline/run.mjs --live             # source + enrich
node pipeline/run.mjs --live --write     # + Attio writeback
